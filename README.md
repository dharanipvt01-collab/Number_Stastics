## 📌 Project Overview

**Number Statistics** is a Python-based project developed as part of the **Veda Technology AI & ML Internship**.

The project analyzes a given list of numbers and performs basic numerical processing. It identifies **even and odd numbers** and calculates the **largest and smallest values** from the list.

The project is implemented using Python and Jupyter Notebook, with a Streamlit interface for interactive usage.

## 📝 Problem Statement

Create a Python program that:

1. Takes a list of numbers.
2. Identifies the even numbers.
3. Identifies the odd numbers.
4. Finds the largest number.
5. Finds the smallest number.
